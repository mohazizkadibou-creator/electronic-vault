# دليل المشتري — Electronic Vault Starter Kit

مرحباً! شكراً لشرائك الحزمة. هذه الحزمة تمنحك **تطبيق خزنة مشفّرة كامل** + **مصنع بناء
تلقائي** ينشر نسخك لكل المنصات. هذا الملف يشرح ما حصلت عليه وكيف تطلق منتجك بسرعة.

## 📦 ما تحتويه الحزمة
```
lib/                    كود التطبيق الكامل (Dart/Flutter)
  core/                 النصوص والترجمة (عربي RTL + إنجليزية/فرنسية/إسبانية)
  models/               Project / ProductInfo
  services/             المصادقة (Argon2id) + الخزنة (AES-256-GCM) + المشاريع
  ui/screens/           شاشة الدخول + لوحة التحكم
.github/workflows/      المصنع: بناء Web + Android + Windows عند كل وسم إصدار
build_scripts/          سكربتات بناء محلية
landing_page/           صفحة هبوط جاهزة (عربي RTL)
sales-kit/              ترخيص تجاري + نسخ جاهزة للنشر + هذا الدليل
setup_and_run.bat       تشغيل محلي بأمر واحد (يفتح في Chrome)
```

## 🚀 التشغيل في 3 خطوات
1. ثبّت [Flutter (stable)](https://docs.flutter.dev/get-started/install).
2. انقر مرتين على `setup_and_run.bat` — يفتح التطبيق في Chrome.
3. أول مرة: أنشئ حساباً (اسم مستخدم + كلمة مرور) وابدأ.

## 🏭 إطلاق منتجك للنشر
1. أنشئ مستودعك الخاص على GitHub وارفع المشروع.
2. عدّل الاسم والعلامة في `pubspec.yaml` و`landing_page/index.html`.
3. أطلق نسخة:
   ```bash
   git tag v1.0.0
   git push origin v1.0.0
   ```
4. المصنع يبني تلقائياً وينشر إصداراً فيه `apk` و`aab` و`web.zip` و`windows.zip` و`SHA256SUMS.txt`.
5. (اختياري) فعّل GitHub Pages لتشغيل نسخة الويب أونلاين.

## 🔧 تخصيص سريع
| ماذا تريد | أين |
|---|---|
| تغيير اسم التطبيق/الحزمة | `pubspec.yaml` (`name`, `description`) |
| تغيير الهوية البصرية | `lib/app.dart` (الألوان/الثيم) |
| إضافة/تعديل نصوص | `lib/core/app_strings.dart` |
| إضافة لغة جديدة | أضف قاموساً في `app_strings.dart` + سجّله في `localization.dart` |
| صفحة الهبوط | `landing_page/index.html` |

## 🔐 ملاحظات أمنية
- كلمة المرور لا تُخزَّن أبداً؛ يُخزَّن ناتج اشتقاق Argon2id مع ملح عشوائي لكل تثبيت.
- لا تُرسل أي بيانات لأي سيرفر خارجي (local-first).
- لهذا الحزمة **مفتوحة المصدر للمشتري فقط** — لا تعِد نشر الكود المصدري نفسه.
